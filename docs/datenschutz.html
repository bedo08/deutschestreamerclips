Datenschutzerklärung

Die Anwendung "Deutschestreamerclips" ist ein privates Werkzeug des Kanalbetreibers. Sie wird ausschließlich vom Betreiber selbst genutzt, um Videos auf den eigenen YouTube-Kanal hochzuladen.

Welche Daten verarbeitet werden

Die Anwendung nutzt die YouTube Data API mit dem Google-Konto des Betreibers. Sie lädt Videos hoch und liest die Kanaldaten des eigenen Kanals. Daten anderer Personen werden nicht erhoben, gespeichert oder weitergegeben.

Speicherung

Der Zugangsschlüssel zum eigenen Konto wird verschlüsselt als Geheimnis in GitHub gespeichert und nur für die Uploads verwendet. Er kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Google API Services

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung.
